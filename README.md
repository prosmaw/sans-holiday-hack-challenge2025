# SANS Holiday Hack Challenge 2025 — Write-Up

**Live site**: https://prosmaw.github.io/sans-holiday-hack-challenge2025/

My write-up for the [SANS Holiday Hack Challenge 2025](https://2025.holidayhackchallenge.com/), covering 21 of the 27 objectives across cloud security (Azure RBAC, storage, and network misconfigurations), web application exploitation (IDOR, JWT/JWKS spoofing, Firebase leaks), core networking and firewalls, digital forensics and reverse engineering, and hardware signal analysis, capped off with a chained RCE-to-privilege-escalation exploit.

Built with [MkDocs](https://www.mkdocs.org) and the [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) theme, based on [crahan/HolidayHackChallengeTemplate](https://github.com/crahan/HolidayHackChallengeTemplate/).

## Running Locally

1. Clone the repository: `git clone https://github.com/prosmaw/sans-holiday-hack-challenge2025.git`
2. Create and activate a Python virtual environment.
3. Install dependencies: `pip install -r requirements.txt`
4. Run `mkdocs serve` to view the site locally at `http://127.0.0.1:8000/`.

The site auto-deploys to GitHub Pages via [GitHub Actions](.github/workflows/deploy.yml) on every push to `main`.

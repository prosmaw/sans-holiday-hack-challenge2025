## Solution

Grace asked me to audit the Azure storage security configuration and identify which storage account has public blob access enabled.
The terminal session connected to the Azure CLI tenant and introduced the mission.

The first task asked to see the Azure CLI help using the command:

~~~bash linenums="1" title="Azure CLI help"
az help | less
~~~

The command gave the list of available commands and options.

![Screenshot 2026-04-20 164733](../img/objectives/o7/Screenshot%202026-04-20%20164733.png)

The second task asked to display the current active account with the command:

~~~bash linenums="1" title="Azure CLI current account"
az account show | less
~~~

The result shows that the account name active is "theneighborhood-sub".

![Screenshot 2026-04-20 164834](../img/objectives/o7/Screenshot%202026-04-20%20164834.png)

The next task asked to list all storage accounts the active subscription can access with the command:

~~~bash linenums="1" title="Azure CLI list subscriptions"
az account storage account list | less

~~~
The result shows the list of storage accounts which follows the pattern: neighordhood1-neighordhood6.

![Screenshot 2026-04-20 165036](../img/objectives/o7/Screenshot%202026-04-20%20165036.png)

The next task asked to show the details of each storage account and identify the one with public blob access using the command:

~~~bash linenums="1" title="Azure CLI show storage account"
az account storage account show --name xxxxxxxxxxx | less

~~~

After checking a couple of them, the account name <code>neighordhood2</code> shows a <code>"allowBlobPublicAccess": true</code>

![Screenshot 2026-04-20 165140](../img/objectives/o7/Screenshot%202026-04-20%20165140.png)

The next task asked to list the containers for the storage account <code>neighordhood2</code>. I used the command:

~~~bash linenums="1" title="Azure CLI list public containers"
az storage container list --account-name neighordhood2
~~~

The command revealed a private and a public container.

![Screenshot 2026-04-20 165339](../img/objectives/o7/Screenshot%202026-04-20%20165339.png)

The next task asked to take a look at the blob list in the public container for the storage account <code>neighordhood2</code>. I used the command:

~~~bash linenums="1" title="Azure CLI list public blobs"
az storage blob list --account-name neighordhood2 --container-name public
~~~

The command revealed the blob list of the public container.
This particular screenshot shows the file of interest <code>admin_credentials.txt</code>.

![Screenshot 2026-04-20 165509](../img/objectives/o7/Screenshot%202026-04-20%20165509.png)

The next task was to download and view the file <code>admin_credentials.txt</code> using the command:

~~~bash linenums="1" title="Azure CLI download public blob"
az storage blob download --account-name neighordhood2 --container-name public --file admin_credentials.txt --file /dev/stdout

~~~

This command with the <code>--file /dev/stdout</code> option shows the content of the file on the screen.

After downloading and displaying the content of the file <code>admin_credentials.txt</code>, the challenge was completed.

![Screenshot 2026-04-20 165922](../img/objectives/o7/Screenshot%202026-04-20%20165922.png)

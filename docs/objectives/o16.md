## Hints

??? tip "Quantgnome Leap"
    When you give a present, you often put a label on it to let someone know that the present is for them. Sometimes you even say who the present is from. The label is always put on the outside of the present so the public knows the present is for a specific person. SSH keys have something similar called a comment. SSH keys sometimes have a comment that can help determine who and where the key can be used.


## Solution
Charlie asked me to explore the quantgnome server, follow the key trail, and recover the final flag.

The intro message explained the PQC theme and asked me to find and execute the key generation program.

![Screenshot 2026-01-03 182304](../img/objectives/o16/Screenshot%202026-01-03%20182304.png)

I started by listing files and checking the SSH directory:

~~~bash linenums="1" title="List files and SSH keys"
ls -a
ls -a .ssh
~~~

The SSH directory shows that there is a public key file. Based on the hint I got, there could be useful information as a comment in this file.

![Screenshot 2026-01-04 002956](../img/objectives/o16/Screenshot%202026-01-04%20002956.png)

Next, I viewed the RSA public key to see the key comment:

~~~bash linenums="2" title="View RSA public key"
cat .ssh/id_rsa.pub
~~~

The comment revealed that the public key is associated to the <code>gnome1</code> account.

![Screenshot 2026-01-04 003025](../img/objectives/o16/Screenshot%202026-01-04%20003025.png)

I checked the hosts file to find the PGC server IP, and I connected as `gnome1`:

~~~bash linenums="3" title="Check hosts and connect"
cat /etc/hosts
ssh gnome1@127.10.10.1
~~~

![Screenshot 2026-01-04 003102](../img/objectives/o16/Screenshot%202026-01-04%20003102.png)

The login succeeded and instructed me to find access for `gnome2`.

![Screenshot 2026-01-04 003128](../img/objectives/o16/Screenshot%202026-01-04%20003128.png)

I enumerated the SSH keys and found the ED25519 key for `gnome2` same way as for `gnome1`:

~~~bash linenums="4" title="Find ED25519 key"
ls
ls -a
ls -a .ssh
cat .ssh/id_ed25519.pub
~~~

![Screenshot 2026-01-04 003306](../img/objectives/o16/Screenshot%202026-01-04%20003306.png)

Using that key, I connected as `gnome2`:

~~~bash linenums="5" title="Connect as gnome2"
ssh gnome2@127.10.10.1
~~~

After successfull connection to gnome2, and was asked to find the information for `gnome3`

![Screenshot 2026-01-04 003440](../img/objectives/o16/Screenshot%202026-01-04%20003440.png)

This time I found a MAYO key, so I pulled the next public key and the `gnome4` account name:

~~~bash linenums="6" title="Find MAYO key"
ls -a
ls -a .ssh
cat .ssh/id_mayo2.pub
~~~

![Screenshot 2026-01-04 003600](../img/objectives/o16/Screenshot%202026-01-04%20003600.png)


I connected as `gnome3`, then listed keys and used the hybrid key to connect to `gnome4`:

~~~bash linenums="7" title="Connect as gnome3 and use hybrid key"
ssh gnome3@127.10.10.1
ls -a .ssh
cat .ssh/id_ecdsa_nistp256_sphincssha2128fsimple.pub
ssh gnome4@127.10.10.1
~~~

![Screenshot 2026-01-04 003917](../img/objectives/o16/Screenshot%202026-01-04%20003917.png)

The login to `gnome4` succeeded and explained the hybrid key details.

![Screenshot 2026-01-04 003928](../img/objectives/o16/Screenshot%202026-01-04%20003928.png)

I inspected the next key as requested, and it pointed to the `admin` account:

~~~bash linenums="8" title="Find admin key"
ls -a .ssh
cat .ssh/id_ecdsa_nistp521_mldsa87.pub
~~~

![Screenshot 2026-01-04 004125](../img/objectives/o16/Screenshot%202026-01-04%20004125.png)

I connected as `admin` to reach the final stage:

~~~bash linenums="9" title="Connect as admin"
ssh admin@127.10.10.1
~~~

![Screenshot 2026-01-04 004246](../img/objectives/o16/Screenshot%202026-01-04%20004246.png)

From the admin shell, I searched for the flag using the `find` command:

~~~bash linenums="10" title="Find the flag"
find / -name flag
~~~

![Screenshot 2026-01-04 012846](../img/objectives/o16/Screenshot%202026-01-04%20012846.png)

The output revealed the flag path under `/opt/oqs-ssh/flag`.

![Screenshot 2026-01-04 012855](../img/objectives/o16/Screenshot%202026-01-04%20012855.png)

I opened the flag file to capture the final value.

![Screenshot 2026-05-28 174421](../img/objectives/o16/Screenshot%202026-05-28%20174421.png)

After submitting the flag, the objective was added to the achievements list.

![Screenshot 2026-05-28 020030](../img/objectives/o16/Screenshot%202026-05-28%20020030.png)

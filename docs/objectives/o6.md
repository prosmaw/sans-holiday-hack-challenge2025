## Solution

Eric asked to help him find and connect to the wardriving rig's service on his motorcycle using Nmap.

A terminal is presented with step by step instructions to accomplish the task.

![Screenshot 2026-04-20 162737](../img/objectives/o6/Screenshot%202026-04-20%20162737.png)

The first task was to run a basic nmap scan of the top 1000 ports on the IP address<code>127.0.12.25</code>. I used the command: 

~~~bash linenums="1" title="Nmap top 1000 ports scan"
nmap 127.0.12.25
~~~

![Screenshot 2025-12-29 094624](../img/objectives/o6/Screenshot%202025-12-29%20094624.png)

After running the command only the TCP port <code>8080</code> is opened.
Task 2 asked to run a Nmap scan of all TCP port. I used the command:

~~~bash linenums="1" title="Nmap full TCP ports scan"
nmap -p- 127.0.12.25
~~~

![Screenshot 2025-12-29 094700](../img/objectives/o6/Screenshot%202025-12-29%20094700.png)

The full TCP scan revealed only port <code>24601</code> assocaited with an unkown service is opened.

Task 3 asked to perform a Nmap scan on the range of IP addresses <code>127.0.12.20-28</code> I used the command:

~~~bash linenums="1" title="Nmap IP range scan"
nmap 127.0.12.20-28
~~~

![Screenshot 2025-12-29 094820](../img/objectives/o6/Screenshot%202025-12-29%20094820.png)

The scan of the IP range revealed that most hosts do not have open port, but the host 127.0.12.23 has the port <code>8080</code> opened.
Task 4 asked check what service is running on port <code>8080</code> for the host <code>127.0.12.25</code>.
I used the command:

~~~bash linenums="1" title="Nmap service detection on port 8080"
nmap -sV -p 8080 127.0.12.25
~~~

![Screenshot 2025-12-29 094942](../img/objectives/o6/Screenshot%202025-12-29%20094942.png)

The command for checking which service is opened on port <code>8080</code> for the host <code>127.0.12.25</code> revealed that the port is running an http service.

Task 5 asked to use the ncat to connect to the host <code>127.0.12.25</code> on port <code>24601</code>.

I used the command:

~~~bash linenums="1" title="Ncat connection to port 24601"
ncat 127.0.12.25 24601
~~~

![Screenshot 2025-12-29 095128](../img/objectives/o6/Screenshot%202025-12-29%20095128.png)

The command revealed the banner of the wardriving rig service.

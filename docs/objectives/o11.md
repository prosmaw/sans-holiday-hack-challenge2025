## Solution

Mark asked to download a disk image and see what secrets the disk is hiding.

In the Items list on the HHC website, the disk image <code>floppy.img</code> is available.

![Screenshot 2025-12-30 101722](../img/objectives/o11/Screenshot%202025-12-30%20101722.png)

## Image Analysis

After downloading the disk image, I ran couple of command on it to analyze the disk contents.

The first command was to see the file type. I used the command:

~~~bash linenums="1" title="Image file type"
file floppy.img
~~~

The <code>file</code> command revealed that the file is the image of a FAT12 disk as Mark said and it is also identified as a DOS/MBR boot sector. The floppy disk is probably bootable.

Next, I tried to view the disk image's partition table with the command:

~~~bash linenums="2" title="Disk partition table"
sudo fdisk -l floppy.img
~~~

This comand revealed that the disk image has a size of 1.41 MiB with 2880 sectors and a single partition.

I later mounted the disk image with the command:

~~~bash linenums="3" title="Mount disk image"
sudo mkdir -p /mnt/img
sudo mount -o loop floppy.img /mnt/img
~~~

After mounting the image, I listed the disk content, and looked through the files. None of them contained anything meaningful. 

![Screenshot 2025-12-30 124628](../img/objectives/o11/Screenshot%202025-12-30%20124628.png)

### Data Extraction

I remembered that Mark said they used to share things by hiding them as deleted files.

So I decided to run <code>testdisk</code> on the drive and check for deleted files.
I used the command:

~~~bash linenums="1" title="Testdisk"
sudo testdisk /dev/loop0
~~~

The command opened the Testdisk tool on the disk image.

![Screenshot 2025-12-30 114354](../img/objectives/o11/Screenshot%202025-12-30%20114354.png)

After selecting enter on the previous page, I got the page to select the partition table type. Since no partition table was detected I selected "None" As recommended by Testdisk.

![Screenshot 2025-12-30 114417](../img/objectives/o11/Screenshot%202025-12-30%20114417.png)

On the next screen I selected the single partition of the disk.

![Screenshot 2025-12-30 114441](../img/objectives/o11/Screenshot%202025-12-30%20114441.png)

After selecting the partition, the content of the disk are listed including deleted files. Two files were deleted, but the <code>all_i-want_for_christmas.bas</code> seems the most obvious since the competition is happening during christmas time.

I proceed with 'C' to copy the selected file.

![Screenshot 2025-12-30 114543](../img/objectives/o11/Screenshot%202025-12-30%20114543.png)

I chose the root directory of the disk as the destination to copy the <code>all_i-want_for_christmas.bas</code> file.

![Screenshot 2025-12-30 114738](../img/objectives/o11/Screenshot%202025-12-30%20114738.png)

I exited the Testdisk tool and run a <code>ls</code> to confirm that the file was recovered.

![Screenshot 2025-12-30 124656](../img/objectives/o11/Screenshot%202025-12-30%20124656.png)

I opened the <code>all_i-want_for_christmas.bas</code> file and looked through it. A base64 encoding stood out.

![Screenshot 2025-12-30 124814](../img/objectives/o11/Screenshot%202025-12-30%20124814.png)

I decoded the base64 string with the command:

~~~bash linenums="1" title="Base64 decoding"
echo "bWVycnkgY2hyaXN0bWFzIHRvIGFsbCBhbmQgdG8gYWxsIGEgZ29vZCBuaWdodAo" | base64 -d
~~~
The flag is revealed to be <code>merry christmas to all and to all a good night</code>.

![Screenshot 2025-12-30 124913](../img/objectives/o11/Screenshot%202025-12-30%20124913.png)

The objective was added to the achievements list.

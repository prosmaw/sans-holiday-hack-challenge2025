## Solution

Janusz said the gnomes brought the neighborhood Wi-Fi down and changed the admin password. 

A URL to access the router web interface was provided. On the website, I noticed that the router was a TP-Link Archer AX1800 Wi-Fi 6 router using the firmware version 1.1.4 build 20230219. 

![Screenshot 2026-05-27 203713](../img/objectives/o14/Screenshot%202026-05-27%20203713.png)

After looking online, I found that the CVE-2023-1389 was associated with that specific firmware version of the router.
This vulnerability allows a command injection in the TP-Link Archer AX21/AX1800 web management interface that can allow unauthenticated remote code execution.

![Screenshot 2026-01-02 135138](../img/objectives/o14/Screenshot%202026-01-02%20135138.png)

I also found a proof of concept at [Fortinet advisory](https://www.fortinet.com/blog/threat-research/botnets-continue-exploiting-cve-2023-1389-for-wide-scale-spread). Based on this proof of concept, I gave a try to a command injection.

I got a "OK" response.

![Screenshot 2026-01-02 140239](../img/objectives/o14/Screenshot%202026-01-02%20140239.png)

This needs to be run twice to see a result, so I ran the command injection again and got the folders on the router.

![Screenshot 2026-01-02 140247](../img/objectives/o14/Screenshot%202026-01-02%20140247.png)

After a couple of online searches I found that the password resides in <code>etc/config/wireless</code>.
A first <code>ls etc</code> revealed folders including a <code>config</code> folder.

![Screenshot 2026-01-02 140318](../img/objectives/o14/Screenshot%202026-01-02%20140318.png)

The <code>ls etc/config/</code> revealed the existence of the <code>wireless</code> file.

![Screenshot 2026-01-02 140408](../img/objectives/o14/Screenshot%202026-01-02%20140408.png)

The <code>cat etc/config/wireless</code> revealed the router configs including the password.

![Screenshot 2026-01-02 140529](../img/objectives/o14/Screenshot%202026-01-02%20140529.png)

After submitting the password, the objective was added to the achievements list.

![Screenshot 2026-05-27 205608](../img/objectives/o14/Screenshot%202026-05-27%20205608.png)

## Solution

Josh asked me to exploit the IDOR (Insecure Direct Object Reference) vulnerability of the Sasabune payment systems to uncover a gnome's true identity. Josh provided this link on a presentation about IDOR: [IDOR presentation](https://www.youtube.com/watch?v=hzrhtHrhwno)

I was provided the receipt of another client and was asked to find the receipt of the gnome.

As visible on the receipt, there is a QR code that clients can scan to pay.
![Screenshot 2025-12-31 132042](../img/objectives/o13/Screenshot%202025-12-31%20132042.png)

After scanning the QR code, I was sent to this website listing the customer name, receipt number and items bought.

![Screenshot 2025-12-31 130259](../img/objectives/o13/Screenshot%202025-12-31%20130259.png)

I looked through the source code of the website through the dev tool of my browser and noticed the endpoint used to retrieve the receipt.
The endpoint only uses the ticket number, this means that I can get any customer information by putting random numbers as id of the endpoint.

![Screenshot 2025-12-31 130744](../img/objectives/o13/Screenshot%202025-12-31%20130744.png)

Appending the endpoint with the found receipt id gave me the information that was displayed on the website.

![Screenshot 2025-12-31 131045](../img/objectives/o13/Screenshot%202025-12-31%20131045.png)

After going through the receipt one by one (obviously not the best option. A script would have been better), I finally found a receipt with a note about 'Frozen Roll' which match a request of the gnome.

![Screenshot 2025-12-31 132003](../img/objectives/o13/Screenshot%202025-12-31%20132003.png)


After submitting the name of this customer, the objective was added to the achievements list.

![Screenshot 2026-04-21 155414](../img/objectives/o13/Screenshot%202026-04-21%20155414.png)
